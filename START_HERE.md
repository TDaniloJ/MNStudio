## 🚀 PRÓXIMOS PASSOS

### 1. Sincronizar Banco de Dados
```bash
cd backend
npm run sync-db
```

### 2. Iniciar Desenvolvimento
```bash
# Terminal 1
cd backend && npm run dev

# Terminal 2
cd frontend && npm run dev
```

### 3. Testar
- Abra http://localhost:5174
- Procure pelo novo sino 🔔 na Navbar
- Vá para Perfil e edite bio + banner
